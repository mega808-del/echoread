# EchoRead · 영어 문장 반복 듣기

**웹 주소:** https://mega808-del.github.io/echoread/

영어 지문을 문장 단위로 나눠 카드로 보여 주고, 문장별 반복 듣기와 전체 연속 듣기를 제공하는 학습 웹앱입니다.
빌드 도구나 외부 라이브러리 없이 `index.html` 한 파일로 동작하며, GitHub Pages + PWA로 휴대폰 홈 화면에 설치할 수 있습니다.

## 모바일에서 설치하기

앱 주소를 연 뒤 아래 순서로 설치합니다.

- **Android · Chrome**: 주소창 오른쪽 `⋮` → **앱 설치** (또는 **홈 화면에 추가**)
- **iPhone · Safari**: 하단 **공유** → **홈 화면에 추가**

설치 후에는 주소창 없이 전체 화면으로 실행되고, 한 번 열어 두면 오프라인에서도 동작합니다.

## 주요 기능

- 영어 지문 자동 문장 분리 (`.`, `?`, `!`, 줄바꿈 / `Mr.` `Mrs.` `Dr.` 등 약어는 끊지 않음)
- 문장 카드별 듣기, 1~5회 반복 재생, 반복 진행 표시
- 전체 문장 연속 듣기, 재생 중인 카드 강조
- 속도 조절(0.75x ~ 1.2x), 음성 선택(남/여 톤), 발음·뜻 표시 토글
- 한글 뜻: 카드의 **자동 번역**(문장별) 또는 **뜻 모두 불러오기**, 어색한 번역은 **수정**으로 직접 교정
- 번역한 문장은 기기에 저장되어 다음 실행·오프라인에서도 그대로 표시
- 직접 입력한 지문은 브라우저에 저장되어 다음 실행 때 복원

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (HTML/CSS/JS, 데이터 포함) |
| `manifest.webmanifest` | 홈 화면 설치 정보 (이름, 아이콘, 색상) |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icons/*.png` | 앱 아이콘 |

## 한글 뜻 번역

자동 번역은 키가 필요 없는 무료 API(MyMemory)를 브라우저에서 직접 호출합니다. 별도 서버나 사전 파일이 없어 앱 용량은 늘지 않습니다.

- 번역 결과는 `localStorage`(`echoread.ko`)에 문장별로 저장되어, 다시 번역하지 않고 재사용합니다.
- 익명 기준 하루 약 5,000자까지 번역할 수 있습니다. 한도를 넘으면 카드에서 직접 입력해 주세요.
- 번역을 요청한 문장 내용은 해당 서비스로 전송됩니다.
- 오프라인에서는 저장된 뜻만 표시되고, 새 문장은 온라인일 때 번역됩니다.

## 수정 후 배포

`index.html`을 수정해 올리면 서비스 워커가 최신 HTML을 먼저 받아오므로 다음 접속 때 반영됩니다.
캐시를 강제로 비우고 싶으면 `sw.js`의 `CACHE = 'echoread-v1'` 부분의 버전을 올려 주세요.

## 로컬에서 실행

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 파일로 직접 열어도 앱은 동작하지만, 서비스 워커는 `http`/`https`에서만 등록됩니다.
